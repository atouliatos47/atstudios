Word to PDF

Open a Word file, check how it looks, then save it as a PDF. The file stays on this computer. Nothing is uploaded.

Drop a Word file here

Works with .docx files. For an old .doc file, open it in Word, choose Save As, pick Word Document (.docx), then open it here.

In the window that opens, set Destination to Save as PDF, then press Save. Chrome remembers this for next time.
